# Data Analyst Roadmap

Suggested pace: around two hours per day. Tasks are milestones, not deadlines; carry unfinished work forward.

## Phase 1 — Health & Welfare Benefits Analytics
1. Data profiling (completed; record actual results).
2. Data-quality investigation: duplicates, status inconsistencies, client-plan mismatches, and date validity.
3. Define eligibility and enrollment rules.
4. Calculate eligible and enrolled employee-plan pairs and enrollment rates.
5. Analyze participation by client, benefit type, location, and month.
6. Write findings and limitations.
7. Build Power BI dashboard.

## Phase 2 — Excel reporting
- Export validated aggregates.
- Build PivotTables and charts.
- Reconcile Excel totals with SQL.
- Write a one-page business summary.

## Phase 3 — Retail Sales Analytics
- Choose a licensed public or synthetic dataset.
- Profile and clean data.
- Analyze revenue, products, and customers.
- Build a dashboard and publish findings.

## Phase 4 — Operations & Data Quality Analytics
- Use synthetic request-level data.
- Analyze turnaround time, SLA compliance, backlog, and exceptions.
- Build a dashboard and document recommendations.

## Phase 5 — Career readiness
- Polish project READMEs and profile README.
- Pin strongest projects.
- Practice SQL joins, aggregations, CTEs, and window functions.
- Tailor resume truthfully to target job descriptions.
- Practice explaining each project and its limitations.

## Daily routine
- 10 min: review progress and choose a deliverable.
- 70 min: hands-on analysis.
- 25 min: validate results and document meaning.
- 15 min: update the log and commit meaningful work.

A GitHub streak is a side effect of consistent work, not a substitute for useful analysis.
