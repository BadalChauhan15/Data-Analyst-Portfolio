# Portfolio Quality Checklist

- [ ] Business problem and stakeholder are clear.
- [ ] Dataset source and synthetic/public status are documented.
- [ ] Table grain and relationships are explained.
- [ ] KPI definitions specify numerator, denominator, and reporting period.
- [ ] SQL is formatted and commented.
- [ ] Data-quality rules and cleaning assumptions are documented.
- [ ] Results are validated against independent totals.
- [ ] Findings are separated from hypotheses.
- [ ] Recommendations are supported by evidence.
- [ ] Dashboard screenshots are readable.
- [ ] README explains how to reproduce the work.
- [ ] No credentials, real personal data, or employer-confidential information.
