## How to use this repository

Start with `projects/01-health-welfare-benefits-analytics/README.md`. Follow the SQL scripts in order, read the documentation, and record measured results rather than assuming or inventing values.

## Working principles

- Start with a business question.
- Preserve raw data and document assumptions.
- Validate calculations and table grain.
- Separate findings from hypotheses.
- Never publish employer-confidential data, real client/employee records, credentials, or secrets.
